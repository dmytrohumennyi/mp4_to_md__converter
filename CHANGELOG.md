# Історія змін

Формат за [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/),
версії за [SemVer](https://semver.org/lang/uk/).

## [1.0.0] — 2026-09-03

Перша версія, перевірена на реальному записі лекції.

### Додано
- Самодостатній `install.sh`: генерує `converter.py`, `converter.env`,
  `requirements.txt`, `USAGE.md`, `assets/beep.wav`, venv і команду
  `lecture-converter`.
- Конвеєр mp4 → mp3 → md одним запуском.
- Робоча папка з назвою відеофайлу і трьома артефактами всередині.
- Markdown з YAML front-matter і часовими мітками.
- Довідка при виклику без аргументів.
- Звуковий сигнал про завершення через згенерований wav.
- Автовизначення GPU з встановленням CUDA-бібліотек у venv.
- Режим `--emit-only` для генерації файлів без інсталяції.
- Пропуск етапів, результати яких уже є (`--force` для перезапису).

### Виправлено
- `LD_LIBRARY_PATH` для CUDA. Пакети `nvidia-cublas-cu12` і
  `nvidia-cudnn-cu12` розміщують `.so` у `site-packages/nvidia/*/lib`,
  куди `ld.so` не заглядає; наслідок —
  `RuntimeError: Library libcublas.so.12 is not found`. Тепер `bootstrap()`
  додає ці теки в оточення до старту процесу через `os.execv`.
- Відкат на CPU, якщо CUDA недоступна: замість traceback конвертер
  повторює прогін з `int8`.
- Автоматичне перемикання на інтерпретатор venv. Раніше
  `python3 converter.py` завершувався помилкою імпорту
  `faster-whisper`, хоча пакет був установлений.
- Тип обчислень `int8` замість неіснуючого `int7` з початкового драфту.
- `install.sh` генерує `USAGE.md`, а не `README.md` — щоб не затирати
  опис репозиторію.
- Модель за замовчуванням `large-v3` замість `large-v2`: краще тримає
  перемикання мови всередині файлу.

### Перевірено
- Генерація файлів, компіляція згенерованого коду, перемикання на venv
  без зациклення, повний прогон на відео з кириличною назвою і пробілом.
- Сигнатури API faster-whisper 1.2.1.
