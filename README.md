# Lecture Converter

Конвеєр обробки записів лекцій: `mp4 → mp3 → md`.

Звук видобувається через ffmpeg, мовлення розпізнається моделлю Whisper
(реалізація faster-whisper), результат зберігається у Markdown з
YAML front-matter — придатний для подальшої підготовки навчальних
матеріалів.

## Особливість репозиторію

Єдиний файл, який потрібно мати, — `install.sh`. Він самодостатній:
код `converter.py` вбудований у нього як heredoc і генерується під час
інсталяції разом з конфігурацією, залежностями та інструкцією.

Через це згенеровані файли навмисно **не комітяться** (див. `.gitignore`) —
єдиним джерелом правди лишається `install.sh`. Правки вносяться в нього,
а не в згенерований `converter.py`, інакше наступний запуск інсталятора
їх перезапише (стара версія зберігається як `converter.py.bak`).

## Швидкий старт

```bash
git clone <URL цього репозиторію> lecture-converter
cd lecture-converter
bash install.sh
```

Далі:

```bash
python3 converter.py lecture01.mp4
```

Або, якщо `~/.local/bin` у `PATH`:

```bash
lecture-converter lecture01.mp4
lecture-converter                  # довідка
```

## Результат

Поруч із відео створюється папка з його назвою і трьома артефактами:

```
lecture01/
  lecture01.mp4   вихідне відео
  lecture01.mp3   видобутий звук (16 кГц, моно, 64 kbps)
  lecture01.md    транскрипт із часовими мітками
```

Markdown містить YAML front-matter (тривалість, мова, модель, дата,
`status: draft`), тож файли лягають в Obsidian чи статичний генератор
сайту без ручної розмітки.

## Вимоги

- Ubuntu 22.04 або новіша (потрібен `apt`)
- Python 3.10+
- ffmpeg
- 6 ГБ вільного місця (модель `large-v3` ~3 ГБ + venv)
- 8 ГБ RAM для `large-v3` на CPU; для GPU-режиму — NVIDIA з CUDA 12

Системні пакети та Python-залежності встановлює сам `install.sh`.

## Параметри інсталятора

| Параметр | Призначення |
|---|---|
| `--yes`, `-y` | неінтерактивний режим |
| `--model NAME` | модель Whisper (`tiny`…`large-v3`) |
| `--no-model` | не завантажувати ваги під час інсталяції |
| `--emit-only` | лише згенерувати файли, без apt/venv/моделі |
| `--help`, `-h` | довідка |

`--emit-only` зручний для перевірки згенерованого коду в CI або на
машині без прав root.

## Параметри конвертера

| Параметр | Призначення |
|---|---|
| `--language uk\|en\|auto` | мова лекції, типово auto |
| `--model NAME` | модель для конкретного запуску |
| `--device cpu\|cuda` | обчислювальний пристрій |
| `--force` | перезаписати наявні mp3/md |
| `--move` | перенести відео у папку, а не копіювати |
| `--no-beep` | без звукового сигналу |
| `--timestamps on\|off` | часові мітки у Markdown |

Постійні налаштування — у `converter.env`, який генерується під час
інсталяції під конкретну машину.

## Продуктивність

| Пристрій | Модель | Година запису |
|---|---|---|
| CPU, 8 ядер | large-v3 / int8 | 40–90 хв |
| CPU, 8 ядер | medium / int8 | 20–35 хв |
| CPU, 8 ядер | small / int8 | 8–15 хв |
| GPU NVIDIA | large-v3 / float16 | 3–8 хв |

На новому записі спершу варто прогнати `--model small`, щоб перевірити
якість звуку, і лише потім запускати повну модель.

## Технічні рішення

**faster-whisper замість openai-whisper.** Реалізація на CTranslate2
приблизно втричі швидша на CPU і не тягне за собою torch (~2.5 ГБ).

**Автоматичне перемикання на venv.** `converter.py` на старті визначає,
що його запустили системним `python3`, і перезапускає себе
інтерпретатором з `./venv` через `os.execv`. Активувати venv вручну
не потрібно.

**LD_LIBRARY_PATH для CUDA.** Пакети `nvidia-cublas-cu12` і
`nvidia-cudnn-cu12` кладуть `.so` всередину `site-packages/nvidia/*/lib`,
куди `ld.so` не заглядає. Той самий механізм перезапуску додає ці теки
в `LD_LIBRARY_PATH` — інакше CTranslate2 падає з
`Library libcublas.so.12 is not found`.

**Відкат GPU → CPU.** Якщо CUDA все ж недоступна, конвертер повторює
прогін на CPU з `int8` замість того, щоб завершитися помилкою.

**Звуковий сигнал через wav, а не PC speaker.** Модуль `pcspkr` у
сучасній Ubuntu зазвичай у чорному списку, а символ `\a` термінали
ігнорують. Тому інсталятор генерує `assets/beep.wav` і програє його
через `paplay`/`aplay`.

## Двомовні лекції

Whisper визначає мову один раз за початком запису. Англіцизми всередині
української розпізнаються нормально — модель сприймає їх як запозичення.
Якщо ж англійською читаються цілі блоки, доцільно або лишити
автовизначення, або розділити запис і обробити частини окремо із явним
`--language`.
